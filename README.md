# Matematik Macerası 🐥🎮

İlkokul ve ortaokul (1 - 8. sınıf) öğrencileri için geliştirilmiş, 3D çizgi film görünümlü interaktif matematik eğitim oyunu.

## 🌟 Özellikler
- **1-8. Sınıf Düzeyleri:** İlkokul ve ortaokula uygun pedagojik zorluk kademeleri.
- **Dört İşlem & Karışık:** Toplama ➕, Çıkarma ➖, Çarpma ✖️, Bölme ➗ ve Karışık Macera 🎲.
- **Görsel Kimlik:** 3D Doğa/Göl arka planı, 3D Sevimli Sarı Ördek maskotu ve 3D Mavi Sayı Blokları.
- **Macera Haritası:** Yıldız toplama ve ada kilitleri sistemi (6 farklı ada).
- **Veli/Öğretmen Analitiği:** İşlem bazlı başarı oranları ve gelişim tavsiyeleri.
- **Web Audio API:** Harici ses dosyası indirmeden tarayıcıda üretilen canlı ses efektleri.
- **Güvenlik:** Sıfır API anahtarı, sıfır harici sunucu bağımlılığı; %100 güvenli ve offline çalışabilir.

## 🚀 GitHub Pages ile Canlı Yayınlama
Bu depoyu GitHub Pages ile anında ücretsiz yayınlamak için:
1. GitHub'da deponuzun **Settings** (Ayarlar) sekmesine gidin.
2. Sol menüden **Pages** bölümüne tıklayın.
3. **Branch** kısmından `main` (veya `master`) ve `/ (root)` seçip **Save** butonuna basın.
4. 1-2 dakika içinde `https://<kullanici-adiniz>.github.io/<depo-adiniz>/` adresinden 7/24 yayına girer!
